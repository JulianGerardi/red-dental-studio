ProcessProceso

How a project moves from question to shipped product.Cómo un proyecto pasa de una pregunta a un producto lanzado.

The stages stay the same from project to project. What changes is how long each one takes.Las etapas son las mismas en cada proyecto. Lo que cambia es cuánto dura cada una.

  1. 01

    ResearchResearch

    User interviews, usability tests and analytics, plus an audit of screens, components and the rules nobody wrote down.Entrevistas con usuarios, tests de usabilidad y analytics, más una auditoría de pantallas, componentes y las reglas que nadie escribió.

  2. 02

    StructureEstructura

    Information architecture, user flows and journeys. Navigation is agreed before any pixel.Arquitectura de información, flujos y journeys. La navegación se acuerda antes que cualquier pixel.

  3. 03

    DesignDiseño

    High-fidelity UI in Figma on a design system shared by web and mobile, reviewed with stakeholders as it grows.UI de alta fidelidad en Figma sobre un design system compartido por web y mobile, revisado con stakeholders a medida que crece.

  4. 04

    PrototypePrototipo

    Working prototypes built with Claude Code, so stakeholders, the CEO and real users try the actual flow.Prototipos funcionales hechos con Claude Code, para que stakeholders, el CEO y usuarios reales prueben el flujo de verdad.

  5. 05

    Validate & shipValidar y lanzar

    Usability tests, A/B tests and KPIs, then a handoff with components that already live in code and in Storybook.Tests de usabilidad, A/B testing y KPIs, y un handoff con componentes que ya viven en código y en Storybook.

AboutSobre mí

I trained as an art director, so I care how a product looks. Years of SaaS work taught me to care more about how it behaves on a busy Tuesday.Me formé como director de arte, así que me importa cómo se ve un producto. Años de SaaS me enseñaron que importa más cómo se comporta un martes cualquiera.

I lead product design from research and information architecture to design systems, high-fidelity UI and interactive prototypes, and I measure the result with analytics and A/B testing.Lidero el diseño de producto desde el research y la arquitectura de información hasta el design system, la UI de alta fidelidad y los prototipos interactivos, y mido el resultado con analytics y A/B testing.

I work side by side with developers from the first sketch, present the work to stakeholders and CEOs, and run user interviews and usability tests so decisions rest on what people actually do.Trabajo codo a codo con los devs desde el primer boceto, presento el trabajo a stakeholders y CEOs, y hago entrevistas y tests de usabilidad para que las decisiones se apoyen en lo que la gente hace de verdad.

My workflow runs through AI: Claude Code turns designs into working prototypes and takes a Figma design system into code, documented in Storybook for the developers. Midjourney and Freepik Spaces help me explore visual directions.Mi flujo de trabajo pasa por la IA: con Claude Code convierto diseños en prototipos funcionales y llevo un design system de Figma al código, documentado en Storybook para los devs. Midjourney y Freepik Spaces me ayudan a explorar direcciones visuales.
