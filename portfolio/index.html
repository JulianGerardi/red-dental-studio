Process5 stages

How a project moves from question to shipped product.

The stages stay the same from project to project. What changes is how long each one takes and how much of it the team already has.

  1. 01

    Research

    Interviews, usability tests and analytics, plus an audit of what already exists: screens, components and the rules nobody wrote down.

  2. 02

    Structure

    Information architecture, user flows and journeys. The navigation gets agreed before any pixel does.

  3. 03

    Design

    High-fidelity UI in Figma on top of a design system and a component library, so web and mobile stay consistent.

  4. 04

    Prototype

    Functional web-app prototypes built with Claude and Cursor. Stakeholders test the real flow instead of a slideshow.

  5. 05

    Validate & ship

    Usability testing, A/B tests and KPIs, then handoff with developers on technical feasibility.

About

I trained as an art director, so I care about how a product looks. Years of SaaS work taught me to care more about how it behaves on a busy Tuesday.

I lead product design from research and information architecture to design systems, high-fidelity UI and interactive prototypes, and I measure the result with analytics and A/B testing.

Lately my workflow runs through AI: Claude and Cursor to build functional prototypes, Midjourney and Freepik Spaces to explore visual directions. It lets a small team test more ideas with real users before committing to one.
